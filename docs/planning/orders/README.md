# Orders

One file per job, named by round (`<round>.md`, short, unique and sortable, such as `S1.1`). Story and Planning
writes it after the owner approves; Building builds it in one pull request.

```
# Order <round>: <title>
Goal · Approval (owner, date, which picture) · Scope (numbered) · Must not move
Expected side effects · Parts needed · Evidence (fixed viewpoints, tests) · Done when
```
